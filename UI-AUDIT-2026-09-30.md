# StackUp Hold'em Academy — UI audit 2026-09-30

Scope: current production Academy in `SkyareCom/stackup.holdem-academy`. The reference repository `.definitivo` was not modified.

## Findings

- Multiple generations of CSS coexist in the production HTML. The inventory before normalization contained 430 `!important` declarations, 24 centered-text declarations, 13 `white-space: nowrap` declarations, 16 `overflow: hidden` declarations, 63 fixed pixel widths and 77 fixed pixel heights. Several are intentional visual controls; the audit focused on editorial/content elements.
- Two global left-alignment patches were duplicated before the main stylesheet.
- The plans description class `.evneed` still had a later legacy `text-align:center` rule.
- Several card text selectors used `nowrap + overflow:hidden + ellipsis`, which can truncate translated or long content.
- Vertical rhythm mixed 4, 6, 8, 10, 12, 14 and 16 px values between sibling content structures.
- Plan/profile card headers combine flexible titles with fixed badges/prices and needed explicit `min-width:0` / wrapping rules.
- Five-column footer already used `minmax(0,1fr)`; it is preserved and asserted by the QA check.

## Normalized production standard

- Screen horizontal margin: **16 px**
- Gap between structures/cards: **12 px**
- Internal element gap: **8 px**
- Editorial card padding: **14 px**
- Editorial text: **left aligned**
- Long editorial copy: wraps naturally; no ellipsis/forced nowrap
- Lists: consistent 20 px indent and 8 px between items
- Cards/media: constrained to available width
- Footer: **5 items, one row**

A final stylesheet `#academy-ui-quality-normalization` is deliberately placed last in `<head>` so legacy rules cannot reintroduce spacing/alignment regressions. `test-layout-quality.js` protects these invariants during Pages deployment.
